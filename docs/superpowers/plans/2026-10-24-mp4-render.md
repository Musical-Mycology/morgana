# MP4 Render Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `npm run render -- --deck <id> --out <file.mp4>` renders a timed deck frame-accurately to 1080p30 H.264/AAC, by making art + nightlight pure functions of deck time and stepping a chrome-free render page in headless Chromium into ffmpeg.

**Architecture:** A pure `engine/authoring/art-clock.ts` computes the art layer stack (with crossfade opacities) and nightlight at any deck time; `ArtStage.renderState` paints that without tweens. A shared `DeckStage` (extracted from the Player) owns one `ArtStage` and the beat stage, driven only by `apply(T)`; `/play` and the new `/render` page both use it. A CLI (`scripts/render.ts` + pure helpers in `lib/render/`) drives `/render` with Playwright and pipes PNG frames + the soundtrack into system ffmpeg.

**Tech Stack:** TypeScript, React 19 / Next 15, GSAP (parity reference only), Playwright (library + test runner), tsx, system ffmpeg/ffprobe, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-24-mp4-render-design.md` — read it before starting any task.

## Global Constraints

- `engine/authoring/art-clock.ts` is PURE (no DOM/GSAP/React at runtime; type-only imports allowed) and is added to `tests/unit/pure-import-graph.test.ts`.
- Eases: GSAP `power2.inOut` is **cubic** — `p < .5 ? 4p³ : 1 − (−2p+2)³/2`; `back.out(2)` = `1 + 3(p−1)³ + 2(p−1)²`. Pinned against `gsap.parseEase` in tests.
- Art durations (ms): cut 0, fade 700, crossfade 900, morph 800, dissolve 1100 — moved from ArtStage into art-clock as `ART_DURATION_MS`. `NIGHT_ENTRY_MS = 200`.
- In host-driven mode (`autoplay={false}`) `CinematicSlide` never calls `runtime.art`, `runtime.applyArt` or `runtime.setNightlight`; the host owns art + nightlight.
- The Player's (and render page's) `apply(T)` stays the ONLY writer of deck time.
- Default render output: 1920×1080, 30 fps, `libx264 -pix_fmt yuv420p -crf 18 -preset medium`, `aac -b:a 192k`, `-movflags +faststart`. Default base URL `http://localhost:3000`.
- ffmpeg/ffprobe come from `FFMPEG_PATH` / `FFPROBE_PATH` or `PATH`; missing → exit 2 with: `ffmpeg not found — install it (macOS: brew install ffmpeg, Debian/Ubuntu/WSL: sudo apt install ffmpeg) or set FFMPEG_PATH.`
- Hand-built browser URLs go through `withBasePath()`; the CLI builds URLs from `--base-url` (which already carries any sub-path) and never imports `withBasePath`.
- Unit: `npx vitest run <file>`; full `npm test` (baseline at branch start: 131 files / 752 tests). E2E: `export LD_LIBRARY_PATH=/tmp/claude-1000/-home-chris-oltyan-projects-morgana--claude-worktrees-morgana-time-animation-78c764/7e066baf-f84a-45f2-ae64-4ba1724b162c/scratchpad/libs/usr/lib/x86_64-linux-gnu` then `npm run test:e2e -- e2e/<name>.spec.ts --project=default`. `library.spec.ts:46` EXDEV is a known env-only failure.

## Review Focus

1. **A frame reached by jumping equals the same frame reached by stepping** — mid-crossfade, mid-nightlight, after a mid-beat art action (Task 6 e2e + Task 2 unit).
2. **Scrubbing `/play` backwards across an art change or a nightlight action** shows the earlier art/nightlight (no leftover from the later state) — the cases sub-project 1 needed workarounds for (Task 5 test).
3. **A transition that starts while the previous crossfade is still running** continues smoothly (outgoing layers fade from their current opacity, no pop) (Task 2 unit).
4. **Ctrl-C or a failing frame mid-render** leaves no half-written MP4 and no orphan Chromium/ffmpeg (Task 8 test of the cleanup function).
5. **Overrun-cut content** (a pinned scene whose art action falls past its boundary) never appears in the render (Task 2 unit).

```ts
 *  reference in tests: these curves must match what ArtStage's tweens produce. */
```

```ts
import type { DeckDoc } from "@/engine/deck-doc";
import type { ArtTransition, StoryAsset as _SA } from "@/engine/deck/types";
import type { StoryAsset } from "@/engine/deck/story-assets";
import { deckLayout } from "./deck-clock";
import { beatTimeline } from "./beat-clock";
import { applyArt } from "@/engine/deck/flatten";
import { isOverlay } from "@/engine/deck/story-assets";

export interface ArtEvent { start: number; duration: number; mode: ArtMode; to: StoryAsset[] }
export interface ArtLayerState { asset: StoryAsset; opacity: number; scale: number; z: number; overlay: boolean }

const seconds = (art: ArtTransition) => (art.durationMs ?? ART_DURATION_MS[art.mode]) / 1000;

/** Every art change in deck order, at the deck time it starts. A pinned scene's content past its
 *  cut boundary is never reached, so neither is its art. `to` is folded against the true prior
 *  stack, so keep/out behave exactly as in sequential playback. */
export function artEvents(doc: DeckDoc): ArtEvent[] {
  const out: ArtEvent[] = [];
  let stack: StoryAsset[] = [];
  const push = (start: number, art: ArtTransition) => {
    stack = applyArt(stack, art);
    out.push({ start, duration: art.mode === "cut" ? 0 : seconds(art), mode: art.mode, to: [...stack] });
  };
  for (const s of deckLayout(doc).scenes) {
    const scene = doc.scenes[s.sceneIdx];
    const reached = (localStart: number) => !s.pinned || localStart < s.length;
    for (const b of s.beats) {
      if (!reached(b.start)) continue;
      const beat = scene.beats[b.beatIdx];
      const beatStart = s.start + b.start;
      if (beat.art) push(beatStart, beat.art);
      for (const w of beatTimeline(beat.timeline)) {
        if (w.action.kind === "art" && reached(b.start + w.start)) push(beatStart + w.start, w.action.art);
      }
    }
  }
  return out;
}

/** The art layer stack at deck time T, with crossfade opacities. Each event is evaluated up to the
 *  next event's start (or T): kept layers sit at 1 (as ArtStage's reuse snaps them), incoming
 *  layers ease in, outgoing layers ease out from their opacity when the event began. */
export function artAt(events: ArtEvent[], T: number): ArtLayerState[] {
  let visible: ArtLayerState[] = [];
  for (let i = 0; i < events.length && events[i].start <= T; i++) {
    const e = events[i];
    const until = i + 1 < events.length && events[i + 1].start <= T ? events[i + 1].start : T;
    const p = e.duration <= 0 ? 1 : clamp01((until - e.start) / e.duration);
    const prev = new Map(visible.map((l) => [l.asset, l]));
    const incoming: ArtLayerState[] = e.to.map((asset, idx) => {
      const overlay = isOverlay(asset);
      const base = { asset, z: idx + 1, overlay };
      if (prev.has(asset) || p >= 1) return { ...base, opacity: 1, scale: 1 };
      if (overlay) { const q = backOut2(p); return { ...base, opacity: clamp01(q), scale: 0.9 + 0.1 * q }; }
      const q = power2InOut(p);
      return { ...base, opacity: q, scale: e.mode === "morph" ? 1.04 + (1 - 1.04) * q : 1 };
    });
    const outgoing = p >= 1 ? [] : visible
      .filter((l) => !e.to.includes(l.asset))
      .map((l) => ({ ...l, opacity: l.opacity * (1 - power2InOut(p)) }));
    visible = [...outgoing, ...incoming];
  }
  return visible;
}
```

```ts
export interface NightEvent { start: number; duration: number; to: number }
export interface NightTimeline { initial: number; events: NightEvent[] }

/** Nightlight changes in deck order: a beat entry whose flattened nightlight differs from the
 *  current value (over NIGHT_ENTRY_MS), and each reached `nightlight` action (over its durationMs). */
export function nightEvents(doc: DeckDoc): NightTimeline {
  const slides = flattenStory(doc.scenes);
  const initial = slides[0]?.nightlight ?? 0;
  const events: NightEvent[] = [];
  let current = initial;
  for (const s of deckLayout(doc).scenes) {
    const scene = doc.scenes[s.sceneIdx];
    const reached = (localStart: number) => !s.pinned || localStart < s.length;
    for (const b of s.beats) {
      if (!reached(b.start)) continue;
      const beatStart = s.start + b.start;
      const entry = slides[b.flatIdx]?.nightlight ?? current;
      if (entry !== current) { events.push({ start: beatStart, duration: NIGHT_ENTRY_MS / 1000, to: entry }); current = entry; }
      for (const w of beatTimeline(scene.beats[b.beatIdx].timeline)) {
        if (w.action.kind !== "nightlight" || !reached(b.start + w.start)) continue;
        events.push({ start: beatStart + w.start, duration: (w.action.durationMs ?? NIGHT_ENTRY_MS) / 1000, to: w.action.to });
        current = w.action.to;
      }
    }
  }
  return { initial, events };
}

export function nightAt(tl: NightTimeline, T: number): number {
  let v = tl.initial;
  for (let i = 0; i < tl.events.length && tl.events[i].start <= T; i++) {
    const e = tl.events[i];
    const until = i + 1 < tl.events.length && tl.events[i + 1].start <= T ? tl.events[i + 1].start : T;
    const p = e.duration <= 0 ? 1 : clamp01((until - e.start) / e.duration);
    v = v + (e.to - v) * p;
  }
  return v;
}
```
